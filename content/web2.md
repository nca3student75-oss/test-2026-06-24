# 📱 2.x — 웹 전용 기능·모바일·스토리 모드

v2.00에서 웹 전용 분기를 선언한 뒤 모바일 UI, 기록·보고서, 화면 모드와 스토리 모드가 빠르게 확장된 단계입니다.

## 이 단계의 핵심
- 보드게임에는 필요하지 않은 웹 전용 편의 기능
- 모바일 가로판과 전체 화면 기록
- 플레이 결과 분석 고도화
- 1인 시작 스토리 모드와 자동 동료 영입


# 상세 버전 기록


## 2026-07-27
### v2.00 — 웹 전용 분기 시작
- 이번 버전부터 웹게임은 보드게임판과 다른 전용 요소를 포함할 수 있도록 버전 표기를 v2 계열로 전환했습니다.
- 기능 내용은 직전 v1.100과 동일하며, 이후 웹 전용 기능은 v2 버전 로그에 이어서 기록합니다.

### v2.01 — 규칙 안내 접기
- 시작 화면의 승리·패배, 초기 자원, 핵전쟁 이후 규칙, 시설 비용, 행동카드 공개, 특수 행동, 자동플레이어 성향 안내를 기본적으로 숨겼습니다.
- 필요할 때 “게임 규칙·카드 구성 안내 보기”를 눌러 펼칠 수 있습니다.

### v2.02 — 현재 상태 시설 비용 표시
- 미건설 방공호 시설에는 현재 핵전쟁 상태에 맞는 건설 비용만 표시합니다.
- 핵전쟁 이전에는 ₩ 2 + 📦 1 / ₩ 1 + 📦 2 / 📦 3, 이후에는 🌾 2 + 📦 1 / 🌾 1 + 📦 2 / 📦 3 형식으로 표시합니다.
- 이미 건설된 시설에서는 비용 문구를 숨기고 시설 효과와 건설 순서만 표시합니다.

### v2.03 — 모바일 접기 / 기본 9라운드
- 모바일 화면에서 게임 설정 전체를 버튼으로 접거나 펼칠 수 있습니다.
- 공개된 위험도 아래의 카드 내역·덱 현황표를 별도 버튼으로 숨길 수 있습니다.
- 생존 승리 기본값을 9라운드로 변경했습니다. 기존 저장 게임은 저장된 라운드 설정을 유지합니다.

### v2.04 — 시설 파괴 라운드 표시
- 핵폭발로 파괴된 방공호 시설 카드에 파괴된 라운드를 표시합니다.
- 파괴된 시설을 다시 건설한 경우에도 최근 파괴 라운드와 재건 상태를 함께 표시합니다.

### v2.05 — 모바일 팝업 제거 / 2라운드 생존 전망
- 라운드 종료 시 사용하던 브라우저 확인 팝업을 제거하고 화면 안의 붕괴·식량 경고만 유지했습니다.
- 플레이 보고서 점수에 향후 2라운드 식량 비축, 핵폭발 피해 대비, 연구 승리 가능성을 반영합니다.
- 보고서에 세 항목의 전망 점수와 해설을 별도로 표시합니다.

### v2.06 — 테스트용 자원 조정 숨김
- 식량·돈·물자를 임의로 증감하는 테스트용 버튼을 기본 화면에서 숨겼습니다.
- 세부 게임 설정의 “테스트용 자원 수동 조정”을 표시함으로 바꾸면 다시 사용할 수 있습니다.
- 이전 저장 게임은 해당 설정이 없을 경우 기본적으로 숨김 처리됩니다.

### v2.07 — 핵폭발 피해 시설 기록
- 플레이 보고서의 핵폭발 피해 기록에 파괴되었던 시설 이름과 파괴 라운드를 명확히 표시합니다.
- 같은 시설이 여러 번 파괴된 경우 각 라운드를 모두 기록합니다.
- 게임 종료 시 재건된 시설은 “이후 재건됨”, 현재도 파괴 상태이면 “현재 미건설”로 표시합니다.

### v2.08 — 한국어 / English 전환
- 세부 게임 설정에서 화면 언어를 한국어 또는 English로 선택할 수 있습니다.
- 언어 변경 시 화면을 다시 불러오며 저장된 게임 진행은 유지됩니다.
- 게임 설정, 카드 이름과 효과, 상태 표시, 주요 진행 안내와 플레이 보고서를 영문으로 표시합니다.

### v2.09 — 오프라인판풍 카드 컬러링 / 테이블 테마
- 카드 색감을 오프라인 인쇄판에 가까운 밝은 인쇄물 느낌으로 조정했습니다.
- 행동카드·시설카드·위험도 카드의 색상 구분을 더 분명하게 하고, 전체 배경을 테이블 위에서 플레이하는 분위기로 바꾸었습니다.
- 기능과 규칙은 v2.08과 동일하며 이번 버전은 디자인 변형 중심의 웹 테마 버전입니다.

### v2.10 — 행동카드 자원 부족 표시
- 행동 실행에 필요한 자원이 부족하면 공용보드 경고 대신 해당 행동카드 안에 부족한 자원과 필요 비용을 표시합니다.
- 자원이 부족한 행동카드는 흐리게 표시하고 선택 버튼을 비활성화합니다.
- 건축·집중 생산·연구·물물교환의 현재 자원 조건을 실시간으로 반영합니다.

### v2.11 — 급조 정비 상태 표시 수정
- 급조 정비는 현재 라운드에 실제 핵폭발 피해 기록이 있을 때만 선택·사용할 수 있습니다.
- 선택 또는 자동 판단 과정에서 사용된 것처럼 잠시 표시되었다가 복원되는 현상을 막았습니다.
- 사용 성공 시에만 카드가 제거되고 “사용됨 / 제거됨” 상태로 변경됩니다.

### v2.12 — 테스트용 자원 조정 기본 숨김
- 식량·돈·물자 +/- 테스트 버튼을 새 게임과 최초 실행에서 기본적으로 숨깁니다.
- 세부 게임 설정의 “테스트용 자원 수동 조정”을 “표시함”으로 바꾼 경우에만 버튼이 나타납니다.
- 기존 저장 게임을 불러올 때는 저장되어 있던 표시 설정을 유지합니다.

### v2.13 — 카드 설명 접기 / 최근 로그 2건
- 하단의 위험도 카드·행동카드·방공호 시설 상세 설명을 기본적으로 접어 두고 버튼으로 펼쳐 보도록 변경했습니다.
- 게임 중에는 각 카드에 적힌 내용을 우선 확인하고, 상세 참조가 필요할 때만 설명표를 열 수 있습니다.
- 버전 로그는 최근 2건만 바로 표시하고 나머지는 “이전 버전 로그 보기” 안에 숨깁니다.

### v2.14 — v2.08 스킨 복원 / v2.13 기능 유지
- 로딩 안정성이 확인된 v2.08의 벙커톤 스킨과 화면 디자인으로 되돌렸습니다.
- v2.09~v2.13의 기능 변경인 행동카드 자원 부족 표시, 급조 정비 사용 조건 수정, 테스트용 자원 조정 기본 숨김, 카드 설명 접기, 최근 버전 로그 2건 표시는 유지했습니다.
- 시작 선 플레이어 설정을 빠른 시작 설정의 자동 실행 캐릭터 수 바로 아래로 이동했습니다.

### v2.15 — 자동플레이어 비상 호출
- 자동플레이어가 현재 공개된 행동카드 중 실제로 실행할 수 있는 행동이 하나도 없으면 비상 호출을 자동 사용합니다.
- 비상 호출로 행동카드 3장을 추가 공개한 뒤 같은 자동플레이어가 새 선택지를 다시 판단합니다.
- 식량 1 부족, 기상이변, 라운드당 1회 사용 완료, 덱과 버림 더미 소진 시에는 사용하지 않습니다.


## 2026-07-28
### v2.16 — 카드 현황표 순서 조정

- 핵폭발 행의 “예비” 칸과 상단 강조 표시에서 현재 남은 수량을 바로 확인할 수 있습니다.
- 긴장 효과로 핵폭발이 추가될 때 예비 수량이 즉시 감소하며, 기존 최대 5장 규칙은 유지됩니다.

### v2.18 — 카드 수량 세부 조절

- 풍작·경제호황·전파간섭·기상이변·정전·긴장·위기·초기 핵폭발 수량을 새 게임마다 조절할 수 있습니다.
- 카드 수량 메뉴는 기본적으로 접혀 있어 일반 플레이 화면에는 보이지 않습니다.

### v2.19 — 테스트용 자원 조절 기본 숨김
- 식량·돈·물자 +/- 조절 버튼은 최초 실행과 새 게임에서 기본적으로 숨깁니다.
- 세부 게임 설정의 “테스트용 자원 수동 조정”을 “표시함”으로 선택한 경우에만 버튼을 표시합니다.
- 저장 게임을 불러올 때는 저장된 표시 설정을 유지합니다.

### v2.20 — 새 게임 시작 후 설정 자동 숨김
- 새 게임 시작 버튼을 누르면 게임 초기화 직후 게임 설정 패널을 자동으로 접습니다.
- 접힌 뒤 버튼 문구는 “게임 설정 펼치기”로 바뀌며, 필요할 때 다시 열 수 있습니다.
- 화면 크기가 바뀌어도 게임 중 설정 패널이 임의로 다시 펼쳐지지 않습니다.

### v2.21 — 지연 로그·번역 최적화·연구 결과 보고서
- 이전 버전 로그는 버튼을 펼칠 때 처음 생성하도록 변경해 초기 DOM 생성량을 줄였습니다.
- 버전 로그와 카드 참조표는 초기 전체 번역 탐색에서 제외하고, 사용자가 펼칠 때 필요한 영역만 번역합니다.
- 연구 제거 카드에 제거 라운드를 기록하고, 플레이 보고서에 제거 카드 목록·업적 인정 여부·연구 성과 평가를 추가했습니다.

### v2.22 — 모바일 카드 보기 / 안내형 진행
- 모바일 행동카드는 간단히 보기 2열과 자세히 보기 1열을 전환할 수 있습니다.
- 방공호 시설은 모바일 간단히 보기에서 2×2로 배치하고 건설 비용을 영역 상단에 한 번만 표시합니다.
- 안내형·빠른 진행·수동 진행을 추가했으며, 빠른 진행에서도 라운드 종료는 직접 확인합니다.

### v2.27 — 안내 축소 / 자동 이름 2줄 / 추가 행동 카드 축약
- 지금까지 정리한 모바일 최적화 화면을 기기 크기와 관계없이 기본 표시 방식으로 적용했습니다.
- 세부 게임 설정에서 데스크톱 화면으로 전환할 수 있으며 선택값을 브라우저에 저장합니다.
- 데스크톱 화면은 전체 설명과 넓은 카드 배치를 우선하고, 작은 화면에서는 가로 스크롤을 허용합니다.

### v2.29 — 모바일 행동카드 2열 고정
- 간단히 2열·자세히 1열 전환 버튼을 제거했습니다.
- 모바일 최적화 화면에서는 행동카드를 항상 간단한 2열로 표시합니다.
- 데스크톱 화면에서는 기존의 자세한 카드 설명을 유지합니다.

### v2.31 — 위험도 영역 행동카드 이동 버튼
- 공개된 위험도 제목 옆에 행동카드 이동 버튼을 추가했습니다.
- 모바일 최적화 화면에서 버튼을 누르면 공개된 행동카드 영역으로 부드럽게 이동합니다.

### v2.32 — 화면 모드 빠른 전환 메뉴
- 화면 상단에 모바일 기본·데스크톱 모드 전환 메뉴를 추가했습니다.
- 세부 게임 설정을 펼치지 않아도 즉시 화면 모드를 바꿀 수 있습니다.
- 상단 메뉴와 세부 설정의 화면 표시 방식은 서로 동기화되며 선택값을 저장합니다.

### v2.33 — 행동카드 영역 위험도 이동 버튼
- 공개된 행동카드 제목 옆에 위험도 이동 버튼을 추가했습니다.
- 모바일 최적화 화면에서 버튼을 누르면 공개된 위험도 영역으로 부드럽게 이동합니다.

### v2.35 — 모바일 행동카드 한 번에 실행
- 모바일 최적화 화면에서 행동카드 버튼을 플레이어·직업·행동명이 포함된 즉시 실행 버튼으로 변경했습니다.
- 한 번 누르면 카드 선택과 실행을 연속 처리하며, 추가 선택이 필요한 행동은 해당 선택 화면으로 바로 이어집니다.
- 데스크톱 화면은 기존 선택 후 실행 방식을 유지합니다.
