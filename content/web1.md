# 💻 1.x — 웹 프로토타입·오프라인 규칙 검증

웹게임의 출발점입니다. 최초 v1.0은 2026-07-06에 확인되며, v1.100까지 오프라인 규칙 검증과 자동플레이어·보고서 기능을 집중적으로 발전시켰습니다.

## 이 단계의 핵심
- 오프라인 규칙을 브라우저에서 반복 실행
- 위험도·연구·핵폭발·시설 처리 검증
- 자동플레이어와 성향 도입
- 비상 호출·추가 행동의 반복 수정
- 말풍선·플레이 보고서로 한 판의 과정 기록


# 상세 버전 기록


## 2026-07-06
### v1.0 — 웹 기반 테스트 프로토타입
- 1~5인 선택, 초기 자원, 위험도 공개, 행동카드 선택/실행, 시설, 연구 승리, 생존 승리, 붕괴도 패배를 포함한 최초 웹버전을 만들었습니다.

### v1.1 — 연구와 협상가 기능 수정
- 연구 행동이 선택지를 띄운 직후 바로 완료 처리되는 문제를 수정했습니다.
- 협상가가 버려진 위험도 카드 1장을 선택해 덱에 되돌릴 수 있게 했습니다.
- 위험도 카드의 버림 더미 흐름을 정리했습니다.

### v1.2 — 핵전쟁 이후 표시 / 로그 구분 / 급조 정비
- 핵전쟁 이전/이후 상태 표시를 강화했습니다.
- 플레이어별 행동 로그를 구분했습니다.
- 긴급 수리를 급조 정비로 바꾸고, 해당 라운드 핵피해 1회 무효 및 사용 후 제거 규칙을 적용했습니다.

### v1.3 — 돈/식량 1 소비 행동카드 3장 추가 공개
- 돈 1을 소비해 행동카드 3장을 추가 공개하는 버튼을 추가했습니다.
- 핵전쟁 이후에는 식량 1 소비로 바뀌도록 했습니다.

### v1.4 — 승리/패배 배너 표시
- 연구 업적 승리, 생존 승리, 붕괴도 패배 시 공용보드 상단에 결과 배너가 표시되도록 했습니다.

### v1.5 — 공동 방공호 체력과 시설 수 통합
- 공동 방공호 체력을 별도 수치가 아니라 건설된 시설 수와 통합했습니다.
- 핵폭발 피해 시 가장 늦게 지은 시설이 파괴되도록 했습니다.

### v1.6 — 행동카드 플레이어 수 +2 / 자동플레이어
- 공개 행동카드 수를 플레이어 수 +2장으로 변경했습니다.
- 자동 실행 캐릭터 1명을 추가할 수 있게 했습니다.

### v1.7 — 자동플레이어 2명 / 위기·핵폭발 복귀 규칙
- 자동 실행 캐릭터를 최대 2명까지 추가할 수 있게 했습니다.
- 위기와 핵폭발은 한 라운드에 2장 이상 모였을 때만 발동하고, 1장만 나오면 덱으로 돌아가게 했습니다.

### v1.8 — 행동카드 공개 수 조정 / 자동 추가 공개
- 매 라운드 행동카드 공개 수를 플레이어 수 +0~+4장으로 조정할 수 있게 했습니다.
- 자동플레이어가 할 만한 행동이 부족하면 돈/식량을 써서 행동카드 3장 추가 공개를 사용할 수 있게 했습니다.

### v1.9 — 연구 업적 승리 목표 설정
- 연구 업적 승리 조건을 1~6장 사이에서 설정할 수 있게 했습니다.
- 연구 업적 표시를 현재/목표 형태로 바꾸었습니다.

### v1.10 — 선 플레이어 순환 / 추가 공개 타이밍 완화
- 자동플레이어를 포함해 선 플레이어가 매 라운드 순환하도록 했습니다.
- 돈/식량 1 소비 추가 공개를 라운드당 1회, 행동 선택 단계에서 언제든 사용할 수 있게 했습니다.

### v1.11 — 자동플레이어 3명 / 생존 라운드 설정
- 자동 실행 캐릭터를 최대 3명까지 추가할 수 있게 했습니다.
- 생존 승리 라운드를 5~9라운드로 조절할 수 있게 했습니다.

### v1.12 — 목표와 핵폭발 피해 설정 확장
- 연구 승리 기본값을 플레이어 수 +2로 바꾸고 최대 7장까지 설정할 수 있게 했습니다.
- 생존 승리 라운드를 최대 10라운드까지 설정할 수 있게 했습니다.
- 시설이 없을 때 핵폭발 피해로 오르는 붕괴도를 +1 또는 +2로 조절할 수 있게 했습니다.

### v1.13 — 위험도 카드 현황표 / 페어 처리 확인
- 위기 2장 동시 공개 시 붕괴도 +1 후 제거되는 흐름을 명확히 했습니다.
- 위험도 카드별 덱, 공개, 버림, 제거, 추가 수량을 확인하는 현황표를 추가했습니다.

### v1.14 — 핵폭발 카드 규칙 수정
- 핵폭발 카드는 기본 2장으로 시작하고 긴장마다 추가되어 최대 4장이 되도록 했습니다.
- 핵폭발은 발동해도 제거되지 않고 덱으로 돌아가며, 연구 제거 시에만 제거됩니다.
- 초기 핵폭발 카드 수를 0~4장으로 조절할 수 있게 했습니다.

### v1.15 — 연구로 제거된 카드 표시
- 연구로 덱에서 사라진 위험도 카드 목록을 표시했습니다.
- 연구 업적은 위기와 핵폭발 제거 시에만 오르도록 정리했습니다.

### v1.16 — 긴장 연구 제거 / 업적 없음
- 긴장은 연구로 제거할 수 있지만 연구 업적은 오르지 않도록 명확히 했습니다.

### v1.17 — 자동플레이어 성향 아이콘
- 자동플레이어 성향을 생존, 연구, 건설, 자원, 위험형으로 나누고 아이콘을 붙였습니다.
- 성향별 행동 선택 우선순위를 다르게 적용했습니다.

### v1.18 — 선택된 행동카드 표시 유지
- 다른 플레이어가 선택한 행동카드가 사라지지 않고 회색 선택됨 상태로 남게 했습니다.
- 누가 어떤 카드를 선택했는지 공개 영역에서 확인할 수 있게 했습니다.

### v1.19 — 선택 취소 후 추가 공개
- 행동카드를 선택한 뒤 실행 전이면 선택을 취소하고 돈/식량 1을 소비해 행동카드 3장을 추가 공개할 수 있게 했습니다.

### v1.20 — 오락실 자동 건설 비효율 수정
- 붕괴도 0일 때 자동플레이어가 오락실을 우선 건설하지 않도록 수정했습니다.
- 성향별 시설 우선순위를 반영했습니다.

### v1.21 — 행동카드 시장 5장 유지 / 식량 추가 행동
- 행동카드가 항상 5장 펼쳐지고, 한 장을 선택하면 즉시 보충되는 시장형 구조를 도입했습니다.
- 행동 후 식량 1을 소비해 추가 행동을 선택할 수 있게 했습니다.

### v1.23 — 행동카드 공개 4장/5장 옵션
- 항상 선택 가능 4장 유지 옵션을 추가했습니다.
- 기존 5장 유지 방식도 선택할 수 있습니다.

### v1.24 — 취소 보강 / 무작위 성향
- 비용 부족 시에도 선택 취소가 가능하게 했습니다.
- 자동플레이어 성향에 🎲 무작위 선택을 추가하고 기본값으로 설정했습니다.
- 돈/식량 1 소비 추가 공개 버튼을 공개 행동카드 위쪽으로 이동했습니다.

### v1.25 — 자동 급조 정비 우선
- 해당 라운드에 핵폭발 ★ 2장 동시 공개로 핵피해가 발생했거나 발동 중이면, 자동플레이어가 급조 정비를 우선 선택합니다.

### v1.26 — 협상가 / 선택 표시 유지
- 협상가의 “카드를 되돌리지 않고 진행” 선택지를 제거했습니다.
- 되돌릴 카드가 없으면 자동으로 다음 효과로 넘어갑니다.
- 라운드 종료 전까지 사람/자동플레이어가 선택한 행동카드가 선택됨 상태로 남습니다.

### v1.27 — 버전 로그 / 위험도 페어 표시
- 웹파일 안에 별도 버전 로그 페이지를 추가했습니다.
- 위기 ★ 또는 핵폭발 ★이 2장 이상 동시에 공개되어 발동 예정일 때 공개 카드에 “페어 발동” 표시가 뜨도록 했습니다.

### v1.28 — 지연 추가 행동
- 식량 1 추가 행동은 자신의 행동 직후가 아니라, 다른 플레이어의 행동이 끝난 뒤 선택하도록 변경했습니다.
- 추가 행동을 하거나 포기한 뒤에는 원래 진행 순서로 돌아갑니다.

### v1.29 — 라운드 전체 1회 추가 행동
- 식량 1 추가 행동은 플레이어별 1회가 아니라 라운드 전체에서 1회만 사용할 수 있도록 변경했습니다.
- 한 플레이어가 추가 행동을 거절해도, 라운드 종료 전까지 추가 행동 후보가 남아 있으면 다른 플레이어에게 계속 물어보도록 조정했습니다.

### v1.30 — 선택 순서 표시 / 추가 행동 전달 확인
- 행동카드가 몇 번째로 선택되었는지 카드에 “1번째 선택”, “2번째 선택”처럼 표시되도록 했습니다.
- 식량 추가 행동을 한 플레이어가 거절해도 다른 후보 플레이어에게 선택권이 계속 넘어가는 흐름을 확인하고 안내 문구를 보강했습니다.

### v1.31 — 취소한 행동카드 선택 순서 제외
- 행동을 실행하지 않고 선택 취소한 카드는 “N번째 선택” 카운트에 포함되지 않도록 수정했습니다.
- 선택 취소 후 다시 선택하면 실제로 실행될 선택 순서에 맞춰 번호가 다시 붙습니다.

### v1.32 — 식량 추가 행동 게임당 제한
- 식량 1 소비 추가 행동의 플레이어별 전체 게임 사용 한도를 설정할 수 있게 했습니다.
- 기존 라운드 전체 1회 제한은 유지하면서, 각 플레이어가 게임 전체에서 몇 번까지 추가 행동할 수 있는지 표시합니다.

### v1.33 — 자동플레이어 지연 추가 행동 판단
- 자동플레이어가 지연 추가 행동 선택권을 받으면 성향에 따라 스스로 사용 여부를 판단합니다.

### v1.34 — 직업별 추가 행동 제한
- 식량 1 추가 행동은 플레이어별 전체 게임 기본 2회로 변경했습니다.
- 추가 행동으로 선택한 직업은 게임 전체에서 직업별 1회만 사용할 수 있도록 제한했습니다.
- 공용보드에 직업별 추가 행동 사용 여부를 표시합니다.

### v1.35 — 급조 정비 제거 수정
- 급조 정비 사용 후 행동카드 덱으로 돌아가 다시 등장하던 문제를 수정했습니다.
- 급조 정비의 일회성 속성(removeAfterUse)을 올바르게 확인해, 사용 후 제거 상태로 표시만 남고 라운드 종료 후 게임에서 제외됩니다.

### v1.36 — 추가 행동 식량 비용 옵션
- 추가 행동의 식량 비용을 0개 또는 1개로 조절할 수 있게 했습니다.
- 기본값은 기존 규칙처럼 식량 1 소비입니다.

### v1.37 — 자동플레이어 성향 무작위 배정
- 자동플레이어 성향 기본값을 “성향 무작위 선택”으로 변경했습니다.
- 게임 시작 시 성향 무작위 선택은 실제 성향 중 하나로 자동 배정됩니다.
- 자동플레이어가 2명 이상 성향 무작위 선택이면 서로 다른 성향이 우선 배정됩니다.

### v1.38 — 핵폭발 이후 자동 물물교환 개선
- 핵폭발 이후 자동플레이어가 협상가의 물물교환을 사용할 때, 돈이 있으면 돈을 식량 또는 물자로 우선 교환하도록 수정했습니다.
- 핵폭발 이후 돈 획득/보유의 가치가 낮아지는 규칙에 맞춰 자동플레이어 판단을 보강했습니다.

### v1.39 — 신중한 조사 되돌리기 보강
- 신중한 조사에서 풍작과 경제호황은 제거하지 않고 덱에 되돌리는 선택으로 처리하도록 수정했습니다.
- 자동플레이어도 신중한 조사 시 위기/핵폭발/긴장이 없으면 풍작·경제호황을 제거하지 않습니다.
- 강제 연구는 기존 의도대로 1장을 반드시 제거합니다.

### v1.40 — 연구 확인 장수 옵션
- 연구 확인 장수 옵션을 추가했습니다.
- 기본값은 신중 조사 1장 / 강제 연구 2장입니다.
- 기존 신중 조사 2장 / 강제 연구 3장은 쉬움 모드로 선택할 수 있습니다.
- 연구소가 있으면 선택한 모드에서 확인 장수 +1장이 적용됩니다.

### v1.41 — 붕괴도 패배 판정 타이밍 수정
- 붕괴도 3 이상 패배가 위험도 공개 직후 즉시 판정되지 않도록 수정했습니다.
- 핵폭발이나 위기로 붕괴도가 3 이상이 되어도 라운드 종료 전까지 급조 정비, 오락실 등으로 회복할 기회를 가질 수 있습니다.
- 붕괴도 패배는 라운드 종료 버튼을 누른 뒤 최종 상태로 판정됩니다.

### v1.42 — 버전 로그 날짜 표기
