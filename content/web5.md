# 💬 5.x — 관계·정책 대화·직접 상호작용

규칙 추가보다 동료가 실제 인물처럼 느껴지도록 관계·공감·대화·행동 복구를 고도화한 단계입니다.

## 이 단계의 핵심
- 식량 부족 등 상황별 정책 대화
- 공감 얼굴과 적극성 보정
- 행동 위탁과 캐릭터별 행동 보고서
- 자동 행동 실패 복구
- 순번·붕괴도 기반 식량 보존 판단
- 플레이어가 캐릭터를 직접 클릭해 안부를 묻는 기능

- 동료 적극성 개입 이벤트를 각 동료의 행동 직전이 아니라 라운드 기본행동 시작 전에 판정하도록 변경.

- 자동 동료 수가 많아질수록 의견 충돌 가능성을 간접 반영하여 개입 발생 임계치를 소폭 완화. 무작위형은 이 인원 압박 계산에서도 제외.
- 위탁 수락 시 P1의 기본 행동권을 요청 동료에게 맡기며, P1 순번에서 현재 실행 가능한 일반 행동카드만 필터한 뒤 성향 가중 무작위로 1회 실행. 잔해 제거·특수 행동·조건 불충족 행동은 후보에서 제외.
- 위탁을 받은 동료는 자기 원래 순번에서도 정상 기본 행동을 수행하므로 턴 순서는 변경하지 않음.
- 위탁 거부(직접 판단) 시 P1은 자기 기본 행동을 유지하고 요청 동료만 해당 라운드 기본 행동 1회를 포기. 추가 붕괴도 페널티 없음.
- 수락/거부 선택지에는 요청 성향에 따라 지지하는 현재 합류 동료 얼굴을 표시. 무작위형은 찬반 어느 쪽에도 표시하지 않음.
- 플레이 보고서에 개입 발생 횟수, 수락/거부, 위탁된 행동, 행동 포기, 캐릭터별 위탁 행동 횟수를 별도 기록. 위탁 행동은 추가행동 통계에 포함하지 않음.
- 무작위형 설명 문구를 `분위기에 크게 휘둘리지 않습니다.`로 간결화.

### v5.14 — 캐릭터 말투 일관성 정리

- 건설형: 짧은 반존대(~네요/~죠/~봅시다)로 통일.
- 자원형: 포근한 살림꾼식 존댓말과 챙김/나눔 중심 표현.
- 위험형: 허세와 행동파식 농담.
- 무작위형: 엇박자 관찰 농담, 위기에서도 분위기에 크게 휘둘리지 않는 표현.
- 영입·핵폭발·상황 반응·적극성 개입·위기 조합 대표 대사를 정리했으며 규칙/AI 가중치는 변경하지 않음.

### v5.15 — 행동카드 사용 흔적 복원
- 일반 행동카드는 사용 후 공개시장에서 제거되는 현행 구조를 유지한다.
- 대신 `actionHistory`의 현재 라운드 기록을 사용해 행동카드 영역 하단에 `이번 라운드 사용 흔적`을 표시한다.
- 각 흔적은 실행 순서, 플레이어/동료 성향, 행동명, 기본 행동·추가행동·위탁 행동 구분을 표시한다.
- 모바일에서는 카드 슬롯을 차지하지 않는 얇은 완료 바 형태로 표시한다.
- 급조 정비의 기존 전용 사용 완료 흔적은 중복하지 않고 그대로 유지한다.

### v5.16 — 순번·붕괴도 기반 식량 보존 판단
- 자동 동료의 식량 보존 압력을 행동 순번, 붕괴도, 현재 식량 여유, 성향을 함께 보고 계산하도록 보강했다.
- 선 플레이어와 붕괴도 0에서는 식량 부족 가능성을 비교적 느슨하게 보고, 후순번이거나 붕괴도 1 이상이면 식량 소비를 점차 강하게 억제한다.
- 붕괴도 1에서 2, 2에서 3으로 올라가는 상황을 특히 경계하도록 압력을 강화했다.
- 후순번에 식량 생산 행동이 보이지 않으면 생존형·자원형을 중심으로 비상 호출을 사용해 식량 행동을 다시 찾는 판단을 추가했다.
- 앞 순번에서는 다른 플레이어의 행동으로 시장에 새 카드가 공개될 가능성을 고려해 비상 호출을 서두르지 않는다.
- 무작위형은 이 순번·붕괴도 기반 적극성/식량 보존 보정에서 제외한다.

### v5.18 — 비행기 제안 우선 보장·영입 거절·협상 덱 순환 전략
- 비행기 탈출 조건을 충족해 `storyEscapeOfferPending`이 되면, 동료 영입이나 다른 선행 팝업 때문에 즉시 열리지 못하더라도 해당 팝업 종료 직후 다시 확인해 제안이 사라지지 않도록 보강했다.
- 영입 보류 3회 소진 후 거절 버튼이 사라져 사실상 강제 영입처럼 보이던 구조를 수정했다. 보류 한도 이후에도 현재 제안은 거절 가능하며 추가 보류 횟수는 증가하지 않는다.
- 영입 단계와 비용/후기 위험도 패널티는 실제 합류한 동료 수를 기준으로 유지한다.
- 자동 동료의 지원 요청·물물교환은 위험도 버림 더미에 발동 후 버려진 `풍작` 또는 `경제호황`이 최소 1장 있을 때만 후보가 된다.
- 버림 더미의 풍작·경제호황 수가 1~4장으로 많아질수록 지원 요청·물물교환의 자동 선택 선호가 단계적으로 높아진다.
- 자동 협상 재투입에서 존재하지 않던 `safeReturnDiscardIndex()` 호출을 제거하고 실제 풍작·경제호황 후보의 인덱스를 사용하도록 수정했다.
- 덱 순환 전략 대화를 추가했다: `경제호황 촉진 / 풍작 촉진 / 웬만하면 하지 않음 / 상황 봐서 함`.
- 덱 순환 대화는 팀 공통 방침으로 2라운드 동안 자동 동료 판단에 강하게 반영되며, 무작위형은 공감 성향에서 제외한다.

### v5.19 — 위험 대응 대화·개전 후 협상 판단 보강
- 덱 순환 전략 대화의 제목을 `위험을 어떻게 줄일까?`로 바꾸고, 선택지를 `경제가 돌아야 버틸 수 있어 / 식량부터 안정시켜야 해 / 괜히 손대지 말자 / 상황을 보면서 움직이자`로 상황형 표현에 맞췄다.
- 선택지 공감 성향을 소폭 배정했다. 경제호황은 자원형, 풍작은 생존형·건설형, 자제는 연구형이 기본적으로 공감하며 무작위형은 기존처럼 공감 시스템에서 제외한다.
- 자동 협상 판단에도 성향별 작은 기본 선호 보정을 추가했다. 생존형은 풍작, 자원형은 전쟁 전 경제호황/전쟁 후 풍작, 건설형은 풍작과 전쟁 전 경제호황을 소폭 선호하며 연구형은 덱 순환을 약간 신중하게 본다.
- 핵전쟁 이후 버림 더미에 풍작이 있으면 지원 요청·물물교환의 순환 가치가 상승하며, 별도 경제호황 지시가 없을 때 풍작을 먼저 재투입한다.
- 핵전쟁 이후 경제호황만 남아 있어도 덱 희석을 통한 위험 페어 억제 가치를 인정해 협상 행동을 완전히 금지하지 않는다.
- 다만 핵전쟁 이후 `경제호황만 존재 + 지원 요청`은 직접 보상이 없어 실익이 낮으므로 큰 음수 보정을 주어 다른 실행 가능한 행동이 있으면 거의 선택하지 않도록 했다. 물물교환은 자체 교환 효과가 있으므로 약한 억제만 적용한다.

### v5.20 — 2026-08-18 — 붕괴도 추가행동·비축 협상·구조 영입 비용 보강
- 붕괴도 1부터 자동 동료의 추가행동 판단에 직접 긴급 가중치를 추가하고, 초반 절약 및 P1 기회 양보 보정이 위기 상황에서는 완화되도록 조정.
- 붕괴도 2 이상에서는 추가행동을 생존 대응 수단으로 더 적극적으로 고려하도록 기준을 강화.
- `식량을 비축하자`는 협상가 행동에서 풍작 재투입 선호에, `돈을 비축하자`는 경제호황 재투입 선호에 약하게 연계. 전용 `위험을 어떻게 줄일까?` 대화 지시가 더 높은 우선순위를 유지.
- 개전 후에는 풍작의 직접 생존 가치를 우선하며, 돈 비축의 경제호황 선호는 약한 보조 수준으로만 유지.
- 구조 연락(3번째 동료) 영입 비용을 핵전쟁 이전에는 `₩1 또는 📦1`, 핵전쟁 이후에는 기존대로 `📦1`로 정리하고 실제 지불 선택 버튼을 제공.

### v5.21 — 2026-08-18 — 주인공 주도 정책 대화 선택
- 한 라운드에 동시에 발동 가능한 정책 대화가 3개 이상이면, 주인공이 먼저 `무슨 이야기를 꺼낼까?`에서 최대 4개 후보 중 하나를 고른 뒤 해당 정책 대화를 진행한다.
- 주인공 주도 대화는 라운드당 최대 1회이며, 10라운드 본편은 게임당 최대 2회, 12라운드 하드는 최대 3회다.
- 선택하지 않은 정책 대화는 소모하지 않으며 조건이 계속 맞으면 다음 라운드에 다시 후보가 된다.
- 비행기 제안, 지하 탈출 단서/제안, 동료 영입, 핵심 위기 팝업, 식량 부족, 풍부한 비축 등 중요 사건이 대기 중이면 정책 대화를 건너뛰어 중요 사건을 우선한다.
- 주제 선택 자체는 정책 효과를 적용하지 않으며, 실제 효과와 공감 보정은 이어서 열린 본 대화의 답변을 선택할 때만 적용된다.

### v5.23 — 2026-08-18 — 주인공 정책 주제 위임·미세 공감 보정
- 주인공 주도 정책 대화 화면을 `직접 선택 3개 + 👂 동료 이야기를 듣자 1개`로 변경했다.
- `동료 이야기를 듣자`를 선택하면 주인공 주도 대화 횟수는 소모하지 않지만, 해당 라운드의 주제 선택 기회는 사용한다.
- 동료 위임은 화면에 보이지 않는 후보를 포함한 전체 발동 가능 정책 풀에서 현재 상황과 성향 가중치를 바탕으로 하나를 선택한다.
- 직접 주제 선택 카드에는 그 주제를 반기는 현재 합류 동료 얼굴을 표시한다. 해당 성향 동료가 없으면 기존 공감 UI 원칙대로 주인공 판단으로 보인다.
- 직접 주제를 고른 순간 해당 동료들에게 본 정책 답변보다 훨씬 작은 `+0.08`의 주제 공감 적극성 보정을 적용한다.
- 동료 위임으로 실제 선택된 정책도 그 주제를 반기는 동료에게 동일한 미세 적극성 보정을 적용한다.
- 무작위형은 기존 원칙대로 주제 공감 적극성 보정 대상에서 제외되며, 동료 위임 화면의 대화 상대 표시에만 등장할 수 있다.
- 이 장치를 통해 붕괴도 0에서도 대화 주도와 공감을 통해 동료 적극성이 소폭 상승할 여지를 만든다.
